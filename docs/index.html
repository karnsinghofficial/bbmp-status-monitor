About this monitor

  • Read-only: every check is a single safe GET request. Nothing is ever submitted, logged in, or paid for on these government systems.
  • Website reachable ≠ service usable: where noted, a check only confirms the server responds — not that a multi-step form, login, or payment flow actually works end-to-end.
  • Confirmation thresholds: a service is only marked DOWN after multiple consecutive failed checks, and only marked recovered after multiple consecutive successful checks, to avoid false alarms from brief blips.
  • This is an independent personal project, not affiliated with BBMP, GBA, or the Government of Karnataka.

Source code & setup instructions on GitHub. Data refreshes automatically — no login required.
